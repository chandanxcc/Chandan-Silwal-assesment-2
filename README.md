## Reflection

### How I Used AI

I used AI tools such as ChatGPT to help me understand programming concepts, explore different coding approaches, and troubleshoot errors when I was stuck. It also helped me learn better coding practices and improve the readability of my programs.

### Challenges Faced

During this portfolio, I found some tasks challenging, especially when working with loops, conditional statements, and debugging unexpected program outputs. Understanding the requirements of certain problems also took extra time.

### How I Solved Them

To overcome these challenges, I practiced writing and testing code regularly, reviewed lecture notes and learning materials, and used AI guidance to clarify concepts that I did not fully understand. I also learned from my mistakes by analyzing error messages and correcting them step by step.

### What I Learned

Through completing this portfolio, I developed a stronger understanding of Python programming and computational thinking. I gained confidence in solving problems independently and learned how AI can be a useful support tool for learning, while still requiring critical thinking and personal effort to create effective solutions.
